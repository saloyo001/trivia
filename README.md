Trivia Quiz Game 

About the Project

The Trivia Quiz Game is a simple, interactive quiz built using HTML, CSS, and JavaScript. It allows users to answer general knowledge and JavaScript questions while trying to achieve the highest score before time runs out.

Features

Displays 5 randomly selected questions each game.

Includes multiple-choice questions.

Uses a 60-second countdown timer.

Tracks the user's score.

Provides feedback when an answer is submitted.

Allows users to move to the next question.

Includes a restart button to play again.

Uses CSS gradients, animations, and hover effects.

Has a responsive design for different screen sizes.

Technologies Used

HTML5 — Structures the webpage.

CSS3 — Styles the quiz and adds animations.

JavaScript — Handles questions, scoring, the timer, and user interactions.

Getting Started

Requirements

You need a web browser and a code editor such as Visual Studio Code.

Installation

Clone or download the project repository.

Open the project folder in Visual Studio Code.

Open index.html in your web browser.

You can also use the Live Server extension in Visual Studio Code to run the webpage.

How to Play

Open the quiz webpage.

Click Start Quiz.

Read each question and select an answer.

Click Submit Answer to check your answer.

Click Next Question to continue.

Try to answer as many questions correctly as possible before the timer reaches zero.

Click Play Again to start a new game.
